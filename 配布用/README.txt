案件管理（動画編集の案件・請求・納期の管理）
================================================

■ はじめかた
1. zip を右クリック →「すべて展開」で解凍します。
2. できた「anken-kanri」フォルダを、消えない場所（ドキュメントなど）に置きます。
3. フォルダの中の「index.html」をダブルクリックすると開きます。
   ・Google Chrome か Microsoft Edge で開いてください。
   ・開いたページをブックマークしておくと、次から簡単に開けます。
   ・インターネットにつながっていなくても使えます。インストールは不要です。

■ できること
・案件タブ　　　：クライアント／案件名／ショート・ロング／単価／本数／着手日／納期を入れて追加
・クライアント別：クライアントごとに「着手中」「着手前」「完了」を分けて表示
・カレンダー　　：着手日から納期までを月のカレンダーに表示（納期切れは赤枠）
・請求　　　　　：月ごと・クライアントごとの請求額。請求書の発行・振込の確認をワンクリックで記録
・完了済み　　　：「完了」ボタンを押した案件がここに移ります

■ データについて（大事）
・入力したデータは、このPCのブラウザの中に保存されます。どこにも送信されません。
・開いたブラウザごとに別々に保存されます（Chrome で入れたデータは Edge では見えません）。
・ブラウザの「閲覧履歴データの削除」で「Cookie とサイトデータ」を消すと、データも消えます。
・シークレットウィンドウ（InPrivate）では保存されません。
・念のため、ときどき右上の「書き出し」でバックアップを取っておいてください。

■ 新しいバージョンにするとき
1. 先に右上の「書き出し」でバックアップを取ります。
2. 新しい zip を解凍し、中身で今の「anken-kanri」フォルダを置き換えます。
3. index.html を開くと、今までのデータがそのまま表示されます。
   表示されないときは「読み込み」で 1. のファイルを選んでください。

■ 別のPCやブラウザに移すとき
今のPCで「書き出し」→ 移したい先で index.html を開いて「読み込み」。
（読み込むと、移した先のデータは書き出したファイルの内容に置き換わります）
