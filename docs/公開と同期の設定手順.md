# 公開と同期の設定手順

スマホで使う・PCとスマホで同期するための、最初に一度だけの設定です。
料金はかかりません。

## 全体のしくみ

- アプリ本体（プログラム）は **GitHub Pages** に置く。URL を開けば PC でもスマホでも使える
- 入力したデータは各端末のブラウザの中と、各自の **Google ドライブのアプリ専用領域**（ドライブの一覧には出ない）に入る
- GitHub に置くのはプログラムだけ。案件のデータは置かれない

## 1. GitHub Pages に公開する

Claude に「公開して」と頼めば、以下を代わりに行う（`gh` コマンドでログイン済みのアカウントを使う）。

1. GitHub に公開リポジトリ `anken-kanri` を作る（無料の GitHub Pages は公開リポジトリが条件）
2. 今のブランチを `main` として送る
3. Settings → Pages で `main` ブランチのいちばん上（/）を公開元にする

数分後に `https://<GitHubのユーザー名>.github.io/anken-kanri/` で開けるようになる。

## 2. Google Cloud で「ログイン用のID」を作る（15 分ほど）

1. <https://console.cloud.google.com/> を開き、Google アカウントでログインする
2. 画面上のプロジェクト選択 →「新しいプロジェクト」→ 名前 `anken-kanri` → 作成
3. 左メニュー「API とサービス」→「ライブラリ」→ **Google Drive API** を検索 →「有効にする」
4. 左メニュー「Google Auth Platform」（または「OAuth 同意画面」）→「開始」
   - アプリ名：`案件管理`、ユーザーサポートメール：自分のメール
   - 対象：**外部**
   - 連絡先メール：自分のメール → 同意して「作成」
5. 「データアクセス」→「スコープを追加または削除」→ 一覧の下の「スコープを手動で追加」に
   `https://www.googleapis.com/auth/drive.appdata` を入れて追加 → 保存
6. 「対象」→「テストユーザー」→ 使う人の Gmail アドレスを追加（自分も必ず入れる）
   - テスト中はここに登録した人（最大 100 人）だけがログインできる
   - 配布先の人に使ってもらうときは、その人のアドレスもここに足す
7. 「クライアント」→「クライアントを作成」
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 名前：`案件管理`
   - 承認済みの JavaScript 生成元に次の 2 つを追加
     - `https://<GitHubのユーザー名>.github.io`
     - `http://localhost:8770`（PC で起動.bat から試すとき用）
   - 「作成」→ 表示された **クライアント ID**（`〜.apps.googleusercontent.com`）をコピー
8. クライアント ID を Claude に渡す（`js/config.js` の `GOOGLE_CLIENT_ID` に入れて公開し直す）

クライアント ID は秘密の情報ではないので、公開されても問題ない。

## 3. 各端末で使い始める

### PC
1. `https://<GitHubのユーザー名>.github.io/anken-kanri/` を Chrome か Edge で開く
2. 今までのデータがある場合：前の画面（起動.bat や index.html）で「⋯」→「書き出し」→ 新しい画面で「⋯」→「読み込み」
3. 右上の「同期を設定」→ Google アカウントを選ぶ → 許可

### スマホ
1. 同じ URL を開く（iPhone は Safari、Android は Chrome）
2. ホーム画面に追加する
   - iPhone：共有ボタン →「ホーム画面に追加」
   - Android：右上の「⋮」→「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面のアイコンから開き、「同期を設定」→ PC と**同じ** Google アカウントでログイン

## 同期のふるまい

- 開いたとき・画面に戻ってきたとき・データを変えたとき（1.5 秒後）に自動で同期する
- 同じ案件を両方で変えた場合は、後から変えた方が残る
- 片方で消した案件は、もう片方でも消える（消した後にもう片方で編集していたら残る）
- Google のログインは 1 時間ほどで切れる。切れたら右上が「タップして同期」になるので 1 回押す
- 電波がないときも使える。次に同期したときにまとめて反映される

## うまくいかないとき

- 「ログインできませんでした」：手順 2-6 のテストユーザーに、そのアドレスが入っているか確認
- 「redirect_uri_mismatch」「origin_mismatch」：手順 2-7 の JavaScript 生成元の綴りを確認（末尾に `/` を付けない）
- 同期ボタンが出ない：`js/config.js` にクライアント ID が入っていないか、ファイルを直接開いている（同期は URL で開いたときだけ）
