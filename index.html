データの扱いについて

どこに保存されるか

  • 入力した案件・請求の状態・請求書の設定（名前・住所・電話番号・振込先など）は、この端末のブラウザの中に保存されます。
  • 開いたブラウザごとに別々です（Chrome と Edge、PC とスマホでは別のデータになります）。
  • 開発者のサーバーなど、ほかの場所には送っていません。

同期を設定したとき

  • データは、あなた自身の Google ドライブの「このアプリ専用の見えない領域」に 1 つのファイルとして保存されます。ドライブの一覧には出ません。
  • このアプリが使える権限はその領域だけです。ドライブにあるほかのファイルを見たり変えたりはできません。
  • 開発者を含め、ほかの人があなたのデータを見ることはできません。
  • Google のログイン情報（約 1 時間で切れる合鍵）は、この端末にだけ保存されます。

アプリ本体について

  • アプリのプログラムは GitHub Pages から配信しています。広告や、利用状況を集める仕組み（アクセス解析など）は入れていません。
  • 同期ボタンを使えるようにするため、開いたときに Google のログイン部品を Google から読み込みます。ログインして同期を設定しない限り、データは送られません。
  • 配信元の GitHub や Google には、一般的なウェブサイトと同じく、アクセスの記録が残る場合があります。

書き出したファイル・請求書の扱い

  • 「書き出し」の JSON ファイルや、保存した請求書（PDF・CSV）には、住所・電話番号・振込先が含まれます。人に送る・共有する場所に置くときは気をつけてください。

データを消すには

  • この端末から：ブラウザの設定で、このサイトの「Cookie とサイトデータ」を削除します（シークレットウィンドウではもともと保存されません）。消す前に「書き出し」で控えを取っておくと安心です。
  • 同期をやめる：歯車の「設定」→「同期」の「この端末の同期をやめる」。この端末のデータと Google ドライブのデータはどちらも残ります。
  • Google ドライブから：パソコンで Google ドライブを開き、右上の設定 →「アプリを管理」→「案件管理」の「オプション」→「非表示のアプリデータを削除」。
